## What is a List?
====================

** A list is a built-in data structure in Python used to store multiple values in a single variable.

Syntax : my_list = [value1, value2, value3]

# Examples :

** Mutable / Changeable

** Allow Duplicate Values

** Can store different data types of data (homogenious & heterogenious)

** We can access list elements using index order

** in python index starts from 0

print(numbers[::-1]) # print in reverse order

# List Comprehension in Python
==================================

** List comprehension is a short and clean way to create a new list from an existing sequence like range, list, tuple, or string.

** It is mainly used to reduce multiple lines of loop code into a single line.

# normal way
numbers = []
for i in range(1,6):
    numbers.append(i)

print(numbers)

# list comprehension
numbers = [i for i in range(1,6)]
print(numbers)

# square of numbers in normal way
squares = []
for i in range(1,6):
    squares.append(i*i)
print(squares)

# square of numbers using comprehension
squares = [i * i for i in range(1,6)]
print(squares)

# Even Numbers normal way
even_numbers = []
for i in range(1,11):
    if i % 2 == 0:
     even_numbers.append(i)
print(even_numbers)

# comprehension
even_numbers = [i for i in range(1,11) if i % 2 ==0]
print(even_numbers)

# convert to uppercase
names = ["ravi", "sita", "kiran"]
for name in names:
    print(name.upper())

upper_names = [name.upper() for name in names]
print(upper_names)

# students grade
marks = [80, 30, 90, 45, 20]
results = ["Pass" if mark>=35 else "Fail" for mark in marks]
print(results)

# GST
prices = [1000, 2000, 5000, 10000]
price_with_gst = [price + (price * 18 /100) for price in prices]
print(price_with_gst)

## What is a Tuple?
====================

** A tuple is a built-in data structure in Python used to store multiple values in a single variable.

** Tuple is similar to List, but the main difference is:
	
		-- List is mutable

		-- Tuple is immutable / not changeable


** Ordered

** Immutable

** Allow duplicate values

** Can store different data types

** Faster than list

** Used to store fixed data		


Syntax : my_tuple = (value-1, value-2, value-3)

courses = ("JAVA", "Python", "GEN AI", "DEVOPS", ".Net", "MERN")
print(courses)

print(courses[0])

print(courses[-1])

print(courses[1:3])

print(courses[-1:-3:-1]) #start is inclusive, end is exclusive
print(courses[:3])

## courses[1] = "AWS" (not possible)

print(courses.index("GEN AI"))

# tuple packing

# tuple unpacking
student = ("Ashok", "Male", 66868686)

## What is a Set?
====================

** A set is a built-in data structure in Python used to store multiple values in a single variable.

** Set is mainly used when we want to store unique values.

** Set does not allow duplicate values.

## Set Features ###

** It is un-ordered

** Mutable

** Doesnot allow duplicates

** Can store different data types

** Doesn't support indexing

** Doesn't support slicing


syntax :   my_set = {value-1, value-2, value-3} 

courses = {"Python", "JAVA", "Python", "DEVOPS"}

print(courses)

## What is a Dictionary?
============================

** A dictionary is a built-in data structure in Python used to store data in key-value pairs.

** Dictionary is used when we want to store data with a meaningful name/key.

## Dictionary Features

** Ordered

** Mutable

** Duplicate keys not allowed, Duplicate values allowed

** Storing data in key-value pair

** Keys must be unique

** Value can be any data type

Syntax ::

my_dict = {
	
	"key-1" : "value-1",
	"key-2" : "value-2"
}

Example :

student = {
    "name": "Ravi",
    "age": 25,
    "course": "Python"
}

-------------------------------------

student = {
    "name": "Ravi",
    "age": 25,
    "course": "Python",
    "marks": 85
}
print(student)
print(student["name"])  # if key not present it gives error
print(student.get("gender"))  # if key not present it gives None
print(student.get("city", "Hyd"))  # If key not present gives default val

## Adding New Key-Value Pair
student["grade"] = "A"
print(student)

student["name"] = "Raj"
print(student)

# Dictionary Operations
print(student.keys())
print(student.values())
print(student.items())

# update() is used to update dictionary values or add new key-value pairs.
student.update({"name": "Ashok"})
print(student)

# pop() removes value based on key.
student.pop("grade")
print(student)

# popItem() removes last inserted key-value pair
student.popitem()
print(student)

# clear : removes all key-value pairs from dictionary
# del : delete entire dictionary from memory

del student["name"]
print(student)

del student

# Working wit Nested Dictionary

students = {
    "s1": {
        "name": "Raj",
        "age": 25,
        "course": "Python"
    },
    "s2": {
        "name": "Anil",
        "age": 35,
        "course": "GEN AI"
    }
}
print(students)
print(students["s1"])
print(students["s1"]["name"])
print(students["s1"].get("name"))

print(students["s2"])
print(students["s2"]["name"])

# Looping Nested Dictionary
for student_id, student_data in students.items():
    for key,value in student_data.items():
        print(key, "--", value)

    print("-----------")

## What is a String?
====================

==> A string is a built-in data type in Python used to store text data.

==> String is a sequence of characters.

==> Characters can be letters, numbers, symbols, or spaces.

Ex: 
        name = "Ashok"

        pan_number = "DB7979DDF"

        pwd = "Ashok@685757"


## String Features

** Ordered data structure

** Immutable / Not changeable

** Supports Indexing

** Supports Slicing

** Allow Duplicate Characters

** Can be created using single quotes, double quotes, or triple quotes

# join() : joins list values into string (we can give delim)

# startsWith() : checks whether string starts with given value.
# endsWith() : checks whether string ends with given value.
# isdigit() : checks whether all characters are digits.
# isalpha() : checks whether all characters are alphabets.
# isalnum() : checks whether all characters are alphabets or numbers.
# format() : Construct a string with dynamic values
